# SpectrumLink 安装与实机测试

## 适用设备

- 泉盛 UV-K1 / UV-K1(8)
- 已安装 F4HWN Labs v6.3.0
- macOS 上的 Chrome 或 Edge
- K1 原生 USB-C 数据线

此原型只接收，不含发射控制。它是 Labs 的独立应用，不替换主固件。

## 安装前

1. 在 UV Studio 中导出当前配置、校准和频率表备份。
2. 确认 UV Studio 识别到的是 F4HWN Labs v6.3.0。
3. 不要在电量过低时安装应用。

## 安装 SpectrumLink.app

1. 打开 UV Studio，连接 K1。
2. 进入 **Apps / 应用**。
3. 选择本项目的 `dist/SpectrumLink.app` 本地文件并安装到空闲应用槽位。
4. 安装完成后断开 UV Studio。SpectrumLink 运行期间会独占 USB 串口，不能同时使用 UV Studio 或 K5Viewer。

删除方法：回到 UV Studio 的应用列表，找到 SpectrumLink 所在槽位后删除；无需重刷 Labs 主固件。

## 启动网页

先确保已安装 Node.js 20 或更高版本。在项目目录执行：

```bash
npm ci
./start.command
```

### macOS 拦截 `start.command`

如果从 GitHub 的“源代码 ZIP”下载项目，macOS 可能显示“Apple 无法验证 `start.command` 是否包含恶意软件”。这是 Gatekeeper 对网络下载、未经 Apple Developer ID 签名和公证的脚本所做的首次启动拦截，不代表源代码已损坏。

打开“终端”，输入 `cd `（后面保留一个空格），将解压后的 SpectrumLink 文件夹拖入终端，按回车。确认终端已位于该项目文件夹后，再执行：

```bash
xattr -dr com.apple.quarantine .
chmod +x start.command
npm ci
./start.command
```

`xattr` 命令只应对从本项目官方 GitHub 仓库下载的特定 SpectrumLink 文件夹执行；不要对整个“下载”目录或用户目录执行。解除该文件夹的隔离标记后，以后可以直接双击 `start.command`。

> 注意：Releases 中的 `SpectrumLink-v3.7.7.zip` 是安装到 K1 的 UV Studio 应用包；电脑端网页、本地服务和 `start.command` 位于 GitHub 自动生成的“源代码 ZIP”中。

也可以打开右上角 **☰ 设置**，先点 **演示**，无需连接 K1 即可检查机械表、数字表、二维频谱、瀑布图和三维地形。

## 横屏副屏与全屏

- 页面针对 1024×768 横屏副显示器排版，也会适配更宽的显示器。
- 点击右上角 **⛶** 进入浏览器全屏；按 `Esc` 退出全屏。
- 主画面只显示身份、仪表和图表。连接、扫描、身份、雷达和导出设置都在右上角 **☰** 抽屉中；关闭抽屉后不会占用画面。
- 六个显示模块都可抓住标题栏拖动，位置会自动保存在浏览器中。拖乱后可用 **☰ → 布局与导出 → 恢复默认布局** 一键还原。

## 自定义身份

打开 **☰ → 身份信息**，可设置：

- 网名
- 主呼号
- 第二呼号
- PNG / JPEG / WebP 头像（不超过 2 MB）

点击 **保存个性化** 后，内容只保存在这台电脑的浏览器中，不会上传到服务器。

## 飞机雷达

1. 默认中心为太原（纬度 `37.825044`、经度 `112.517125`），半径 `250` 海里；也可打开 **☰ → 飞机雷达** 修改。
2. 填写要观察位置的纬度、经度，或点击 **使用当前位置**。
3. 设置半径 5–250 海里，然后点击 **保存个性化**。
4. 在 **地形后台** 中选择：默认的 **在线开源 3D** 使用无需密钥的 NASA 卫星影像和 Mapterhorn 真实高程数据，展示真实地理山体；卫星影像与高程瓦片都由 SpectrumLink 本机代理并缓存，浏览器无需直连境外地形站点。**本地 3D** 是不联网的程序地形后备；**二维卫星** 适合显卡性能不足时使用。系统会忽略零星瓦片错误，只有真实地形在首次加载阶段连续失败时才自动切换到本地 3D。
5. 页面每 15 秒通过本机服务读取一次网络 ADS-B 数据。雷达下方每 15 秒轮播一架飞机，依据 ICAO 机型代码按需加载对应的 GLB 真机模型；未收录或加载失败时回退到对应比例的程序模型。一个周期内依次展示飞出窗口、45° 完整全机、发动机/舷窗特写和三维山体俯瞰镜头。页面展示呼号、注册号、机型、高度、速度、航向、距离和方位，模型可直接拖动 360° 查看；点击轮播卡片可固定选择，点击“详情”可查看运营方、航线与机场等资料。

实时位置优先来自 [adsb.lol](https://www.adsb.lol/docs/open-data/api)，不可用时切换到 adsb.fi；机型与航线资料来自 ADSBDB。它们与 K1 频谱数据彼此独立。页面不生成模拟飞机：网络不可用会显示“数据不可用”，实时结果为 0 会如实显示 0。

## 身份区域

在 **☰ → 身份信息** 中可设置头像、网名、所在城市、主呼号、呼号颜色、第二呼号和个性 Slogan。第二呼号、城市和 Slogan 均可留空。左上身份区和 Slogan/呼号区组成连续板块，Slogan 与大呼号位于绿色内框中，信号模块不再重复呼号；下方信号模块将数字表放在机械表上方。

## 连接实机

1. 在 K1 上进入 `F+7 → SpectrumLink`，屏幕显示 `SPECT LINK`。
2. 用原生 USB-C 线连接 Mac。
3. 打开右上角 **☰ 设置**，点击 **连接 K1**，在浏览器设备选择框中选择 K1 的 USB 串口。
4. 正常握手顺序为：网页显示“等待 K1” → 收到 HELLO → “K1 已连接” → 约 0.5 秒内出现首个 sweep。
5. 浏览器每 500 ms 发送心跳。连续 2 秒没有心跳时，K1 会停止扫频、恢复原接收状态，并显示 `USB LOST`。

## 功能验收

逐项记录结果：

- [ ] 64 个频点同时出现在二维频谱、瀑布图、三维历史中。
- [ ] 机械指针表与数字 S 表随峰值 dBm 同步变化。
- [ ] 页面速率至少达到 2 sweep/s。
- [ ] 中心频率和 400K / 800K / 1.6M / 3.2M 跨度切换正确。
- [ ] 与 F4HWN 自带频谱对比，同一稳定信号的峰值频率落在相邻采样格内。
- [ ] 点击瀑布图只选择频率，不立即调谐；点击“监听”后才有接收音频。
- [ ] “停止监听”恢复扫频。
- [ ] 拔下 USB 后 K1 在 2 秒内显示 `USB LOST`，正常接收状态恢复。
- [ ] 重新连接并点击连接后可继续扫频。
- [ ] 按 `EXIT` 返回 Labs，原频率、带宽和音频状态恢复。
- [ ] 1024×768 横屏下没有页面滚动，三种频谱、双信号表和飞机雷达均可见。
- [ ] 六个模块均可从标题栏拖动，不能拖出画布，刷新后位置仍保留。
- [ ] 呼号、网名和头像刷新页面后仍保留。
- [ ] 全屏按钮可进入全屏，`Esc` 可退出。

若出现异常，先点击 **诊断信息** 保存 JSON，再记录 K1 屏幕、当前频率、跨度和操作步骤。不要先调整扫描时序，否则会丢失原始问题现场。

## 安全说明

- SpectrumLink 不调用发射接口，PTT 在应用中被忽略。
- 显示的是顺序 RSSI 扫描，不是 SDR 的 I/Q 或 FFT；快速跳变信号可能被漏过。
- dBm 来自 F4HWN 校正值，不等同于实验室仪器校准结果。
- 首次实机测试中若出现无法退出、音频未恢复或频率异常，长按关机再开机，并在 UV Studio 中删除应用后反馈诊断文件。
